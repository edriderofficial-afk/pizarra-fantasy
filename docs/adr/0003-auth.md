# ADR 0003 — Autenticación e identidad

- Estado: aceptado (Fase 0; se implementa en la Fase 2)

## Decisión

1. **Usuario de Pizarra**: Supabase Anonymous Auth en el primer arranque. Opcionalmente se vincula Apple o Google para conservar el Premium al cambiar de dispositivo. `app_user_id` de RevenueCat = id de Supabase.
2. **Cuenta de LALIGA Fantasy**: login en el flujo oficial (WebView/AuthSession). El token se guarda **solo** en el dispositivo (`expo-secure-store`). El backend nunca lo recibe.
3. Para deduplicar y vincular datos, el cliente envía `HMAC-SHA256(provider_user_id, secret)`, nunca el id en claro.
4. Refresco de token con reintentos y backoff. Si falla, pantalla explícita de **"Reconectar cuenta"** con el estado de la sesión visible.
5. Feature flag remoto para desactivar el proveedor si cambia la API.

## Pendiente
